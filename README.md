# Udemy Clone

A simple frontend clone of the Udemy website built using **HTML and CSS**.

## Features

* Navigation bar with search
* Course categories
* Sale banner
* Recommended courses section
* Popular courses section
* Recommended topics
* Footer section
* Font Awesome icons
* Google Fonts

## Live Website

https://inthusha20241647-commits.github.io/Udemy-Clone-Project/

## Technologies Used

* HTML5
* CSS3
* Font Awesome
* Google Fonts

## Purpose

This project was created to practice **HTML, CSS, Flexbox, responsive layouts, and basic website structure** by recreating the design of an online learning platform.
